# Local To Do 数据库结构说明

## 1. 基本信息

- 引擎：SQLite 3（rusqlite，bundled）
- 文件：`%APPDATA%\com.localtodo.desktop\local-to-do.db`
- 日志模式：WAL；同步级别：NORMAL；开启外键约束；忙等待 5 秒
- 结构版本：`PRAGMA user_version = 4`
  - v1 → v2：仅新增 `lists.deleted_at` 列，不清空数据
  - v2 → v3：仅新增 `tasks.reminder_enabled` 列（默认 1，保持旧任务原有提醒行为），不清空数据
  - v3 → v4：新增 `tasks.recurrence_count` 列（默认 0）；旧版本“复制任务”产生的同系列记录合并为一条（保留未完成或最新一条，按规则换算已重复次数），其余记录软删除并取消待触发提醒，不清空用户数据
- 主键：业务表使用 UUID v4 字符串；历史表使用自增整数
- 时间：时间戳统一为 UTC 毫秒（INTEGER）；到期日期为本地日期字符串 `YYYY-MM-DD`；时间为 `HH:MM`

## 2. 表结构

### lists（清单）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | 清单 ID |
| name | TEXT | 清单名称 |
| color | TEXT | 颜色（十六进制，如 #2f6fed） |
| icon | TEXT | 图标标识（预留） |
| sort_order | INTEGER | 排序 |
| created_at | INTEGER | 创建时间（UTC ms） |
| deleted_at | INTEGER | 软删除时间；NULL 表示未删除 |

已删除清单仍保留在表中，其下任务的 `tasks.deleted_at` 写入同一时间戳。恢复清单时按该时间戳整组回滚，任务不会丢失。索引：`idx_lists_deleted`。

### recurrences（重复规则）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | 规则 ID |
| kind | TEXT | daily / weekdays / weekly / monthly / yearly / custom |
| interval | INTEGER | 间隔，如每 2 天 |
| weekdays | TEXT | 逗号分隔的星期数字，1=周一 … 7=周日 |
| month_day | INTEGER | 每月/每年的日（1–31，可空） |
| base_date | TEXT | 初时间点（用户设置的初始日期），下次发生由它 + 规则 + 已重复次数计算 |
| created_at | INTEGER | 创建时间 |

### tasks（任务）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | 任务 ID |
| list_id | TEXT FK→lists.id | 所属清单，级联删除 |
| title | TEXT | 任务名称 |
| note | TEXT | 备注（多行文本，可为空） |
| is_important | INTEGER | 0/1 重要标记 |
| is_completed | INTEGER | 0/1 完成状态 |
| completed_at | INTEGER | 完成时间 |
| due_date | TEXT | 不重复任务为到期日期；重复任务为下一次任务（下次日期）的日期 `YYYY-MM-DD` |
| due_time | TEXT | 到期时间 / 下次日期时间 `HH:MM` |
| reminder_offset | INTEGER | 提前分钟数，0 为准时，NULL 为不提醒 |
| reminder_enabled | INTEGER | 该任务的提醒开关（0/1，默认 0；v3 迁移时旧任务为 1） |
| reminder_at | INTEGER | 实际提醒触发时间（UTC ms），提醒关闭时为 NULL |
| recurrence_id | TEXT FK→recurrences.id | 重复规则，规则删除时置 NULL |
| recurrence_count | INTEGER | 已重复次数（v4 新增）；重复任务的下次日期 = 初时间点 + 规则推进该次数 |
| series_id | TEXT | 重复系列标识（兼容旧数据；新模型下重复任务始终只有一条记录） |
| parent_task_id | TEXT | 旧版本生成下一周期时的父任务（兼容字段，新数据为 NULL） |
| my_day | TEXT | 加入“我的一天”的日期；NULL 表示未加入 |
| sort_order | INTEGER | 手动排序 |
| created_at | INTEGER | 创建时间 |
| updated_at | INTEGER | 修改时间 |
| deleted_at | INTEGER | 软删除时间；NULL 表示未删除 |

索引：`list_id`、`reminder_at`、`series_id`、`deleted_at`。

### task_steps（任务步骤）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | 步骤 ID |
| task_id | TEXT FK→tasks.id | 所属任务，级联删除 |
| title | TEXT | 步骤内容 |
| is_completed | INTEGER | 0/1 |
| sort_order | INTEGER | 排序 |

### reminder_schedules（提醒计划）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | 计划 ID |
| task_id | TEXT FK→tasks.id | 所属任务，级联删除 |
| trigger_at | INTEGER | 触发时间（UTC ms） |
| status | TEXT | pending / fired / missed / cancelled |
| fired_at | INTEGER | 实际触发时间 |
| created_at | INTEGER | 创建时间 |

索引：`(status, trigger_at)`。调度线程每 20 秒查询一次 `status='pending' AND trigger_at<=now`。

### task_history（任务历史）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK AUTOINCREMENT | 记录 ID |
| task_id | TEXT | 任务 ID（不设外键，任务删除后保留历史） |
| task_title | TEXT | 当时任务名称 |
| action | TEXT | 动作类型（create/update/complete/uncomplete/delete/restore 等） |
| detail | TEXT | 详细描述 |
| at | INTEGER | 时间 |

最多保留 3000 条，超出后删除最旧记录。

### notes（独立笔记）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | 笔记 ID |
| title | TEXT | 标题 |
| body | TEXT | 正文（纯文本 / Markdown） |
| created_at | INTEGER | 创建时间 |
| updated_at | INTEGER | 修改时间 |
| deleted_at | INTEGER | 软删除时间 |

### app_settings（应用设置）

| 字段 | 类型 | 说明 |
|---|---|---|
| key | TEXT PK | 设置键 |
| value | TEXT | JSON 编码的值 |

主要键：

- `theme`：`dark` / `light`
- `notifications`：已废弃的全局提醒开关（仅为兼容旧数据保留，不再参与提醒逻辑）
- `timezone_auto`：是否自动跟随 Windows 系统时区（默认 true）
- `timezone`：手动选择的 IANA 时区（如 `Asia/Shanghai`）；自动模式下为空
- `close_to_tray`：关闭窗口时最小化到托盘
- `autostart`：开机自启
- `start_minimized`：开机启动时最小化
- `auto_backup`：自动备份开关
- `backup_interval_hours`：自动备份间隔小时
- `last_backup_at`：上次备份时间（UTC ms）
- `sound_enabled`：提醒时是否播放提示音
- `sound_path`：自定义提示音文件的绝对路径（仅 WAV；空表示使用系统默认提示音）

## 3. 数据关系

```
lists 1 ── n tasks
tasks 1 ── n task_steps
tasks 1 ── n reminder_schedules
recurrences 1 ── n tasks
tasks.series_id / parent_task_id  → 重复系列内的任务链
notes 独立于 tasks（笔记与任务备注互不依赖）
```

## 4. 备份格式（JSON）

```json
{
  "format": "local-to-do-backup",
  "version": 1,
  "app_version": "1.1.1",
  "created_at": 1795429000000,
  "data": {
    "lists": [...],
    "recurrences": [...],
    "tasks": [...],
    "task_steps": [...],
    "notes": [...],
    "task_history": [...],
    "reminder_schedules": [...],
    "app_settings": {...}
  }
}
```

恢复时按 `reminder_schedules → task_steps → task_history → tasks → notes → recurrences → lists` 顺序在单个事务内重建，避免外键冲突。

## 5. 维护建议

- 不要使用第三方工具在应用运行时直接写入数据库；如需手工检查，请以只读模式打开，或在退出应用后操作。
- 需要清理空间时，优先使用“最近删除 → 清空”，而不是直接删除数据库文件。
- 数据库结构和 JSON 备份格式均为平台无关设计，未来 Android 版本可复用任务、清单、笔记、重复规则与提醒模型。
