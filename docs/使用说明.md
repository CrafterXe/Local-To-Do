# Local To Do 使用说明

## 1. 界面结构

应用采用三栏布局：

- 左栏：应用标识、搜索框、智能视图（全部任务 / 我的一天 / 重要 / 计划内 / 已完成）、自定义清单、备忘录、历史记录、最近删除、设置。
- 中栏：当前视图标题、任务数量、快捷添加框、任务列表。
- 右栏：任务详情面板（点击任务后出现）。

## 2. 添加任务

1. 在中栏顶部“添加任务，按 Enter 保存”输入任务名称。
2. 按 Enter 或点击右侧“添加”按钮即可创建。
3. 在“我的一天”视图添加时，任务会自动加入今天；“计划内”视图会默认使用今天的到期日期；其他视图会加入当前清单。

需要更多设置时，点击任务打开右侧详情面板。

## 3. 任务详情

详情面板支持：

- 修改任务名称（自动保存）
- 添加步骤（子任务），勾选完成
- 标记/取消重要
- 加入/移出“我的一天”
- 设置到期日期与具体时间（小时、分钟分开输入，确认后保存）
- 设置提醒（不提醒、准时、提前 20 分钟、提前 1 小时、提前 1 天、自定义天/小时/分钟）
- 设置重复周期
- 更换所属清单
- 编辑多行备注（自动保存）
- 删除任务

日期与提醒面板采用“临时编辑 + 确认保存”：点击“确认”才写入，点击“取消”、点击面板外部或按 Esc 都会放弃本次修改；打开后未做修改时直接关闭不会写数据库。修改日期会保留原有小时和分钟。

所有修改都会在约 0.45 秒内自动保存，无需手动点击保存按钮。

## 4. 提醒

- 设置到期日期后，默认自动设置“准时提醒”；也可手动选择提前提醒或不提醒。
- 提醒使用 Windows 原生通知，由应用后台调度线程驱动，不依赖页面定时器。
- 关闭主窗口后应用会留在系统托盘，提醒继续工作。
- 应用重新启动后会自动重建尚未触发的提醒。
- 如果电脑休眠或应用未运行导致错过提醒：
  - 错过 24 小时以内：启动后会补发一次，并在标题后标注“（延迟提醒）”；
  - 超过 24 小时：标记为 missed，不再打扰。
- 同一任务同一时间点的提醒只会触发一次，修改任务不会造成重复弹窗。
- 提醒触发时会同时播放提示音（可在“设置 → 通知与提醒”关闭）。默认使用系统提示音，也可选择本地 WAV 文件、试听或恢复默认；音频文件缺失或无法播放时只记录日志并提示，不影响通知与调度。
- 可在“设置 → 通知与提醒”关闭通知，或点击“发送测试”验证系统通知权限。

> 说明：从托盘菜单选择“退出”会真正结束程序，此时提醒不会在后台触发；下次启动时会按上述补发规则处理。应用没有注册 Windows 任务计划程序，这是为了保证稳定性和可预测性。

## 5. 重复任务

详情面板“重复”支持：

- 每天 / 每个工作日（周一至周五）
- 每周（可指定周一至周日中的多天）
- 每月（可指定 1–31 日）
- 每年
- 自定义：每隔 N 天、N 周、N 个月

完成重复任务后：

- 当前任务进入已完成；
- 自动生成下一次待办，继承重复规则、清单、重要标记、备注与步骤；
- 历史记录保留。

特殊情况处理：

- 每月 31 日：遇到只有 30 天的月份使用当月最后一天；2 月使用 28 日或闰年 29 日；
- 每年 2 月 29 日：非闰年顺延为 2 月 28 日；
- “跳过本次”会把到期日推进到下一周期，不生成完成记录；
- 删除重复任务时可选择“仅删除本次”或“删除整个系列”。

## 6. 清单管理

- 点击“我的清单”右侧“+”新建清单，可选择颜色。
- 拖动清单标题可调整顺序（也可聚焦后用 Alt + ↑/↓），顺序会立即保存，重启后保持。
- 点击清单右侧“⋯”可重命名、改色、排序或删除。
- 删除清单时必须选择：把任务移动到其他清单，或连同任务一起删除（连同删除时清单与任务都会进入“最近删除”，可整体恢复）。
- 不允许删除最后一个清单。
- 清单会显示未完成任务数量。

## 7. 笔记

- 点击左栏“备忘录”进入独立笔记视图。
- 支持新建、编辑标题与正文、删除、搜索。
- 正文为纯文本 / Markdown 文本，500 毫秒自动保存。
- 笔记与任务备注相互独立，不会互相转换。

## 8. 搜索

左栏顶部搜索框可同时搜索任务标题、任务备注和笔记标题/正文。搜索结果点击后跳转到对应内容。

## 9. 已完成、最近删除与历史

- “已完成”：查看已完成任务，可恢复为未完成。
- “最近删除”：分为已删除任务与已删除清单，显示删除时间，可单独恢复或永久删除；永久删除与“清空”均有二次确认。恢复清单会一并恢复其任务与清单顺序，不会产生重复记录。
- “历史记录”：查看任务创建、修改、完成、删除等操作记录（最多保留 3000 条）。

## 10. 设置

- 外观：深色 / 浅色主题。
- 通知与提醒：开关通知、提示音开关、自定义提示音（选择/试听/恢复默认）、查看下一次提醒、发送测试通知。
- 启动与窗口：关闭窗口时最小化到托盘、开机自动启动、开机启动时最小化到托盘。
- 数据与备份：显示数据库/备份/日志路径、统计信息、自动备份周期、立即备份、导出 JSON/CSV、从备份恢复。
- 关于：版本与隐私说明。

## 11. 快捷键与窗口

- Enter：在快捷添加框中创建任务。
- Esc：关闭弹出面板。
- 窗口大小和位置会被记忆，下次启动恢复。
- 托盘图标左键单击可显示主窗口，右键菜单提供“打开主窗口 / 新建任务 / 退出”。
