# Local To Do 已知问题与限制

以下为 1.0.0 版本已知的行为边界和限制，均已在文档中如实说明，而非隐瞒。

## 1. 提醒与后台运行

1. **完全退出后不会后台提醒**：从托盘菜单选择“退出”会结束进程，此时没有后台服务。下次启动应用时会检查并补发 24 小时内错过的提醒。应用没有注册 Windows 任务计划程序，以避免不可预测的唤醒与权限问题。
2. **提醒需要应用处于运行状态**：可以最小化到托盘，提醒继续工作；但电脑关机或应用退出期间不会弹窗。
3. **触发精度约 20 秒**：调度线程每 20 秒轮询一次，提醒可能在设定时间后 0–20 秒内出现。
4. **睡眠唤醒补发上限 24 小时**：超过 24 小时的提醒会被标记为 missed，不再补发，避免开机后大量堆积。
5. **每个任务仅一个提醒**：同一任务不能同时设置多个提醒时间。
6. **Windows 通知可能被系统抑制**：勿扰模式、通知总开关、单应用通知权限都会影响横幅显示。请在系统设置中允许 Local To Do 通知，并用设置页“发送测试”验证。
7. **通知身份已自动登记**：应用启动时写入 `HKCU\Software\Classes\AppUserModelId\com.localtodo.desktop`，解决未安装（或缺少开始菜单快捷方式）的 Win32 程序 Toast 被系统丢弃的问题。
8. **当前构建环境无法确认横幅视觉展示**：本机桌面会话对包括 PowerShell 自带通知在内的所有 Toast 均不渲染横幅（对照测试同样不可见），但 Windows 通知平台已接收应用通知（`LastNotificationAddedTime` 更新）。因此“通知横幅可见”列为待人工确认，未伪造为通过。

## 2. 重复任务

1. 每月 29/30/31 日会根据当月实际天数收缩到最后一天（例如 31 日规则在 2 月为 28/29 日）。
2. 每年 2 月 29 日在非闰年顺延为 2 月 28 日。
3. 修改重复规则只影响当前系列中未完成的任务；已完成的历史任务保留原规则记录。
4. 删除重复任务时提供“仅删除本次”和“删除整个系列”，没有回收站中按系列批量恢复的入口。

## 3. 数据与备份

1. **自动备份仅在应用运行时执行**：退出期间不会备份；每次启动后会检查是否到期。
2. 自动备份最多保留 20 份，更早的备份会被清理。
3. 一键恢复只接受 JSON 备份；`.db` 快照用于手工排查或高级恢复。
4. 数据位于 `%APPDATA%\com.localtodo.desktop`。在启用漫游配置的企业环境中，该目录可能被系统同步。
5. 历史记录最多保留 3000 条。
6. “最近删除”只保留软删除的任务；彻底删除后无法恢复。

## 4. 界面与交互

1. 任务排序接口已实现，但当前版本未提供拖拽排序的界面入口。
2. 笔记为纯文本 / Markdown 源码编辑，没有富文本工具栏或 Markdown 预览。
3. 主题为手动切换（默认深色），不会在运行中自动跟随 Windows 主题变化。
4. 搜索使用 SQLite `LIKE` 匹配，不支持拼音、模糊纠错或高级查询语法。
5. 步骤（子任务）仅作为检查清单，不能单独设置日期或提醒。
6. 没有多窗口或分屏支持。

## 5. 平台与打包

1. 当前仅提供 Windows x64 版本；Android 版本未开发，仅在架构上预留了平台无关的数据模型、重复规则计算和 JSON 备份格式。
2. 本次交付使用 Windows 自带 IExpress 生成安装包（`publish\LocalToDo-Setup-1.0.0.exe`），因为官方 NSIS 打包时从 GitHub 下载 NSIS 组件超时失败。NSIS 配置仍保留，联网后执行 `npm run tauri build` 即可生成官方包。
3. IExpress 安装包的限制：`/Q` 静默安装参数不可靠，请双击正常安装；安装进度窗口由 Windows 自解压程序提供，界面较朴素。
4. 安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”。请核对文件来源后选择“仍要运行”。
5. 应用未实现自动更新，需要手动下载新版本安装包覆盖安装。

## 6. 其他

1. 不提供云同步、多设备同步或账号体系；这是产品定位（本地优先、完全离线），不是缺陷。
2. 无遥测、无广告、无网络请求。
3. 若数据库文件被外部程序占用或损坏，应用可能无法启动；恢复方法见《备份与恢复说明》灾难恢复章节。
