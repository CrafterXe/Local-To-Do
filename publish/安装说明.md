# Local To Do 安装说明

## 1. 系统要求

- Windows 10 1809 及以上 / Windows 11（推荐 Windows 11）
- 64 位操作系统（x64）
- Microsoft Edge WebView2 运行时（Windows 11 已内置；Windows 10 若缺失，安装程序会自动安装）
- 约 200 MB 可用磁盘空间
- 无需联网、无需注册账号、无需许可证

## 2. 安装包位置

可交付安装包：

```
publish\LocalToDo-Setup-1.0.0.exe
```

双击后按提示完成安装，无需管理员权限：

- 程序安装到 `%LOCALAPPDATA%\Programs\LocalToDo`
- 开始菜单创建“Local To Do”快捷方式
- “设置 → 应用 → 已安装的应用”中出现 Local To Do
- 安装完成后自动启动应用

说明：官方 NSIS 安装包需要在打包时从 GitHub 下载 NSIS 组件，本次构建环境网络超时，未能生成；因此使用 Windows 自带 IExpress 打包，安装与卸载流程已实测（见 `docs\测试报告.md` 第 5 节）。本项目仍保留 Tauri NSIS 配置，联网环境下执行 `npm run tauri build` 即可生成官方安装包。

也提供免安装版本：`publish\LocalToDo.exe`，双击即可运行（数据位置相同）。

## 3. 首次启动

1. 从开始菜单搜索“Local To Do”并启动。
2. 首次启动会自动创建数据库和默认清单“任务”。
3. 默认使用深色主题，可在“设置 → 外观”切换为浅色。

## 4. 数据位置

所有数据保存在当前 Windows 用户的数据目录，不会写入安装目录：

```
C:\Users\<用户名>\AppData\Roaming\com.localtodo.desktop\
├── local-to-do.db        # SQLite 数据库（主数据）
├── local-to-do.db-wal    # SQLite WAL 日志
├── local-to-do.db-shm    # SQLite 共享内存文件
├── backups\              # 自动/手动备份（JSON + .db 快照）
└── logs\app.log          # 运行日志（超过 2 MB 自动轮转）
```

设置页会直接显示以上路径，并提供“打开数据目录”“打开备份目录”按钮。

## 5. 开机自启

默认关闭。需要时在“设置 → 启动与窗口 → 开机自动启动”中手动开启，随后可再开启“开机启动时最小化到托盘”。应用不会在未经同意的情况下写入启动项。

## 6. 卸载

通过“Windows 设置 → 应用 → 已安装的应用 → Local To Do → 卸载”，或运行安装目录中的 `uninstall.ps1`。

卸载会停止程序、移除开始菜单快捷方式与程序文件，并弹出确认：是否同时删除个人数据。

- 选择“否”：保留 `%APPDATA%\com.localtodo.desktop`，以后重装可继续使用原有任务与笔记。
- 选择“是”：同时删除数据库、备份与日志。

便携版 `publish\LocalToDo.exe` 不写入系统安装信息，直接删除文件即可；如需清除数据，手动删除上述数据目录。

## 7. 升级

直接运行新版本安装包覆盖安装即可。数据库使用 `PRAGMA user_version` 管理结构版本，升级时会自动执行迁移。升级前建议在设置页点击“立即备份”。

## 8. 常见问题

- 收不到 Windows 通知：应用启动时会自动登记通知身份（AUMID），但仍需在“Windows 设置 → 系统 → 通知”中允许 Local To Do 发送通知，并确认未开启“勿扰模式”。可在设置页点击“发送测试”验证。
- 窗口关闭后程序仍在运行：这是“关闭窗口时最小化到系统托盘”的默认行为，用于保证提醒继续工作。需要完全退出时，请右键托盘图标选择“退出”或使用托盘菜单。
- 安装时出现 SmartScreen 提示：安装包未做数字签名，点击“更多信息 → 仍要运行”即可。程序完全离线，不联网验证。
- 为什么没有 NSIS 安装包：打包时需从 GitHub 下载 NSIS 组件，构建环境网络超时；已改用 Windows 自带 IExpress 生成安装包，功能与卸载流程完整。联网后可执行 `npm run tauri build` 生成官方 NSIS 包。
